# Roadmap

The current release keeps the product small: Markdown artifacts, structural
checks, deterministic resume, and Codex/OpenCode projections. Future work can
add adapters or richer review helpers when they have a clear file contract and
preservation tests.

Potential follow-up areas include more native harness renderers, improved
interactive work-item selection, and clearer diagnostics for substantive
specification quality. These remain proposals. The product does not promise a
database, an approval engine, an external service, an analytics pipeline, or
model-specific workflow policy.
